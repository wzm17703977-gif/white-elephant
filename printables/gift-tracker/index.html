How to use the gift tracker

  1. Fill in the player order before you start. Draw it with the number generator or printable number cards.
  2. When a gift is opened, write what it is on that player’s row.
  3. Each steal gets a tick in that gift’s row. When all boxes are ticked, the gift stays where it is.
  4. At the end, write down who took each gift home. Handy for thank-you notes.
